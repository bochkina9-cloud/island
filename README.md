# Остров (Island)

Браузерная игра о выживании на архипелаге в духе Don't Starve — без мистики.
Рисованный 2,5D: плоские рисунки в объёмном мире, наклонная камера, день и ночь, свет костра.

Играть: https://bochkina9-cloud.github.io/island/

## Что уже есть (прототип 0.1)
- Остров генерируется по зерну: пляжи, луга, лес, скалы, пресные пруды, лагуны.
- Сбор руками и инструментами, инвентарь из 12 слотов + рука, перетаскивание слотов.
- Крафт: топор, кирка, копьё, факел, верёвка; постройки: костёр, сундук, шалаш.
- Здоровье, сытость, вода; еда, приготовление на костре, отравление сырым мясом.
- День, сумерки, ночь: ночью видно только у костра и с факелом.
- Кабаны: бродят, злятся, если подойти близко, дают мясо.
- Смерть на выбор: «мягко» (очнуться в лагере, вещи на месте гибели) или «классика».
- Сложность: лёгкая, обычная, суровая.
- Карта с туманом войны.
- Сохранения: 3 слота в браузере, автосохранение на рассвете и раз в 2 минуты, экспорт и импорт файла.

## Управление
WASD — идти · клик — идти/действовать · E или пробел — действие рядом · 1–0, −, = — предметы ·
ПКМ по слоту — выбросить · C — крафт · M — карта · колесо — масштаб · Esc — пауза · H — помощь.

## Разработка
```bash
npm install
npm run dev     # http://localhost:5173
npm test        # тесты логики
npm run build   # сборка в dist/
```

- `src/game` — логика без графики (генерация мира, симуляция, сохранения), покрыта тестами.
- `src/render` — Three.js: земля, вода, спрайты, освещение; `art.ts` — временная векторная графика.
- `src/ui` — интерфейс, меню, управление.
- `docs/PLAN.md` — план; `docs/ART_GUIDE.md` — как делать спрайты.
