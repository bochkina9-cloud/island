# Остров (Island)

Браузерная игра о выживании на архипелаге в духе Don't Starve — без мистики.
Рисованный 2,5D: плоские рисунки в объёмном мире, наклонная камера, день и ночь, свет костра.

Играть: https://bochkina9-cloud.github.io/island/

## Что уже есть (версия 0.2 — вертикальный срез)
- Архипелаг по зерну: стартовая «Бухта спасения», Лесной и Скалистый острова, между ними море.
  - Лесной: лианы (быстрая верёвка), много ягод и кабанов, пруд.
  - Скалистый: камень, кремень, гнёзда чаек с яйцами; пресной воды нет — берите флягу.
- Плот (ставится на воду у берега) и весло: плавание, высадка, трюм на 6 слотов.
- Шторм раз в 2–4 дня с приметами заранее: ливень, ветер, костры прогорают быстрее, без укрытия холодно, плот в море сносит и может разбить.
- 14 рецептов: топор, каменный топор, кирка, копьё, удочка, весло, факел, верёвка, кокосовая фляга; костёр, сундук, шалаш, дождесборник, плот.
- Рыбалка с берега и с плота, яйца, жарка на костре; фляга на три глотка, дождесборник.
- Здоровье, сытость, вода; день и ночь со светом костра и факела; кабаны.
- Смерть на выбор: «мягко» или «классика»; три уровня сложности.
- Карта архипелага с туманом войны и названиями открытых островов.
- Сохранения: 3 слота, автосохранение, экспорт и импорт; сохранения 0.1 переносятся на новый архипелаг с вещами.

## Версия 0.3 — сезоны и еда
- **Сухой сезон** и **сезон дождей** по 7 дней. В засуху трава желтеет, хочется пить чаще, костёр может поджечь сухую траву — пожар перекидывается на кусты, деревья и шалаш; тушится водой из фляги. В сезон дождей — частые ливни и штормы, костры гаснут быстрее, еда портится быстрее.
- **Порча еды**: свежесть видна полоской на слоте; несвежая еда сытит хуже, испорченная становится гнилью. В сундуке еда портится вдвое медленнее.
- **Солеварня** на пляже выпаривает соль из морской воды в сухой сезон. **Солонина** и **солёная рыба** почти не портятся.
- 17 рецептов, новая вкладка крафта «Еда».

## Управление
WASD — идти · клик — идти/действовать · E или пробел — действие рядом · 1–0, −, = — предметы ·
ПКМ по слоту — выбросить · C — крафт · M — карта · колесо — масштаб · Esc — пауза · H — помощь.

## Разработка
```bash
npm install
npm run dev     # http://localhost:5173
npm test        # тесты логики
npm run build   # сборка в dist/
```

- `src/game` — логика без графики (генерация мира, симуляция, сохранения), покрыта тестами.
- `src/render` — Three.js: земля, вода, спрайты, освещение; `art.ts` — временная векторная графика.
- `src/ui` — интерфейс, меню, управление.
- `docs/PLAN.md` — план; `docs/ART_GUIDE.md` — как делать спрайты.
